后台管理不在这个网址上

你现在打开的是发在 GitHub Pages 上的静态展示版。Pages 只分发静态文件， 不会运行 Python，也没有数据库 —— 而后台要靠后端校验口令、读写数据库， 所以这块在这里用不了，登录框和上传功能都不会出现。

真正的后台一直在你自己的电脑上。改内容、传图片都在那儿做， 做完重新导出一次，这个网址就更新了。

  1. 在项目目录里跑 start.bat（或 python run.py --port 8800）
  2. 浏览器打开 http://127.0.0.1:8800/admin.html，用你设的口令登录
  3. 改完内容跑 deploy\pages.bat（macOS / Linux 是 ./deploy/pages.sh）
  4. 一两分钟后这个网址就同步好了

想要一个公网也能直接管理的后台，得有一台自己的服务器跑完整版 （systemd + nginx + HTTPS），见项目里的 deploy/README.md。
